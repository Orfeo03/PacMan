Pac-Man Game 
A personal recreation of the classic Pac-Man arcade game, built as a game-development project. The goal is to guide Pac-Man through a maze, collect points, and avoid enemies.
About the Project
This project is a chance to practice programming through a familiar arcade game. It focuses on implementing game mechanics, keyboard-controlled movement, and the logic behind an interactive game.
Gameplay
Navigate the maze, collect the available dots, and try to survive encounters with the ghosts. The challenge is to clear the maze while avoiding enemies.
Controls
Use the movement controls provided in the game to navigate the maze.
Getting Started
1. Clone or download this repository from GitHub.
2. Open the project in the development environment appropriate for its source code.
3. Run the game's entry-point file or main application class.
Setup note: Specific installation commands and dependencies depend on the files included in this repository.

Project Goals
- Practice game logic and programming fundamentals.
- Work with movement and collision mechanics.
- Build an interactive project based on a classic arcade concept.
- Improve problem-solving skills through game development.
